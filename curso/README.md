# Design para o Teu Negócio
### O essencial do design gráfico em 3 horas

> Um curso prático para empreendedores e pequenos negócios que querem criar uma imagem profissional sem contratar um designer, e sem precisar de nenhum programa em particular.

---

## Para quem é

- Donos de pequenos negócios, freelancers e criadores de conteúdo.
- Quem faz os próprios posts, flyers ou cartões e sente que "falta qualquer coisa".
- Não é preciso experiência nem nenhum programa em particular: os conceitos aplicam-se no Canva, Figma, Photoshop, PowerPoint ou em papel e lápis.

## Como funciona

Ao longo do curso vais construir **a identidade visual do teu próprio negócio**. Cada disciplina termina com um exercício que acrescenta uma peça. No fim tens um **kit de marca** pronto a usar:

| Disciplina | Peça que constróis |
|---|---|
| 1. Pensar antes de desenhar | Ficha da marca + moodboard |
| 2. Cor | Paleta de cores com códigos |
| 3. Tipografia | Par de fontes + escala de tamanhos |
| 4. Composição e layout | Um flyer redesenhado (antes/depois) |
| 5. Logótipo e identidade | Logótipo simples + variações |
| 6. Design no dia a dia | Guia de marca de 1 página + 3 peças reais |

Para tornar tudo concreto, acompanhamos um negócio fictício: a **Padaria Ló**, uma padaria de bairro que quer parecer mais profissional sem perder o lado acolhedor.

## Estrutura de cada aula

1. **Conceito**: a ideia em poucas linhas.
2. **Exemplo**: o certo e o errado, lado a lado.
3. **Dica prática**: o que fazer já.

No fim de cada disciplina: **exercício** + **mini quiz** de 3 perguntas + **resumo**.

## O que levas no fim

- Uma marca com personalidade definida e coerente.
- Paleta de cores, fontes e logótipo prontos a usar.
- Um guia de marca de 1 página para não voltares a improvisar.
- Uma checklist para rever qualquer peça antes de a publicar.
