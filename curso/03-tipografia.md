# Disciplina 3 · Tipografia

**Objetivo:** escolher e combinar fontes que transmitam a personalidade da marca e organizar a informação por importância.
**Duração:** ~30 min · 3 aulas
**Peça que constróis:** par de fontes + escala de tamanhos

---

## Aula 3.1 · Famílias de letra e o que transmitem

### Conceito
A forma das letras tem personalidade, tal como a cor. As 5 grandes famílias:

| Família | Como é | O que transmite | Exemplos gratuitos |
|---|---|---|---|
| **Serifada** | Com "pezinhos" nas pontas | Tradição, confiança, elegância | Playfair Display, Lora, Merriweather |
| **Sem serifa** | Linhas limpas, sem pés | Moderno, claro, direto | Inter, Montserrat, Poppins |
| **Manuscrita** | Imita escrita à mão | Pessoal, artesanal, afetivo | Caveat, Pacifico, Dancing Script |
| **Display/decorativa** | Muito expressiva | Impacto, carácter forte | Bebas Neue, Abril Fatface |
| **Monoespaçada** | Todas as letras com a mesma largura | Técnica, tecnológica | Space Mono, IBM Plex Mono |

### Exemplo
- ❌ Padaria Ló numa fonte monoespaçada tipo código: parece uma empresa de software.
- ✅ Padaria Ló numa serifada calorosa (Lora) ou numa manuscrita suave (Caveat): parece feita à mão, com tradição.

### Dica prática
Fontes **manuscritas e decorativas** são ótimas para títulos curtos e péssimas para texto corrido. Nunca escrevas um parágrafo inteiro com elas.
Fonte gratuita, legal e fácil de usar em qualquer lado: **Google Fonts** (fonts.google.com).

## Aula 3.2 · Combinar duas fontes

### Conceito
A regra de ouro: **no máximo 2 fontes**. Uma para títulos (com personalidade), outra para texto (legível). Mais do que isso parece desarrumado.

Para combinar bem, procura **contraste com harmonia**:
- Serifada nos títulos + sem serifa no texto (ou o contrário). É a combinação mais segura.
- Manuscrita/decorativa nos títulos + sem serifa simples no texto.
- **Evita** duas fontes parecidas mas não iguais (ex.: duas sem serifa diferentes). Parece um erro, não uma escolha.

Truque: podes usar **uma só família** com pesos diferentes (Bold nos títulos, Regular no texto). É sempre coerente.

### Exemplo · Combinações que funcionam
| Títulos | Texto | Ambiente |
|---|---|---|
| Playfair Display | Inter | Elegante e moderno |
| Lora | Source Sans 3 | Tradicional e legível |
| Caveat | Nunito | Artesanal e simpático |
| Bebas Neue | Montserrat | Forte e enérgico |
| Montserrat Bold | Montserrat Regular | Limpo, uma só família |

**Padaria Ló:** títulos em **Lora** (tradição), texto em **Nunito** (simpático e legível), e **Caveat** pontualmente para pormenores tipo "feito hoje".

### Dica prática
Testa sempre o par com texto real do teu negócio (nome, preços, morada), não com "Lorem ipsum". Há fontes lindas que ficam estranhas com acentos portugueses (ç, ã, õ). Confirma que os têm!

## Aula 3.3 · Hierarquia: o que se lê primeiro

### Conceito
**Hierarquia** é a ordem em que os olhos leem uma peça. Quem olha decide em 2–3 segundos se continua. Por isso tem de ser óbvio o que é mais importante.

Ferramentas para criar hierarquia:
1. **Tamanho**: o mais importante é o maior.
2. **Peso**: negrito destaca.
3. **Cor**: a cor de destaque chama a atenção (lembra-te: só 10%).
4. **Espaço**: elementos com mais espaço à volta ganham importância.
5. **Posição**: lemos de cima para baixo, da esquerda para a direita.

Uma **escala de tamanhos** fixa evita improvisos. Exemplo simples (multiplica por ~1,5 a cada nível):

| Nível | Uso | Tamanho (post 1080px) |
|---|---|---|
| H1 | Título principal | 72 px |
| H2 | Subtítulo | 48 px |
| H3 | Destaque / preço | 32 px |
| Texto | Informação | 24 px |
| Pequeno | Morada, notas | 18 px |

### Exemplo
- ❌ Flyer onde "PROMOÇÃO", o nome da loja, o horário e a morada estão todos no mesmo tamanho e negrito. Nada se destaca, logo nada se lê.
- ✅ "Pão de Deus · 2 por 1€" enorme, "Só às sextas" médio, nome e morada pequenos em baixo. Lê-se em 3 segundos.

### Dica prática
**Teste do semicerrar:** afasta-te do ecrã e semicerra os olhos. O que ainda consegues ver é o que se lê primeiro. É isso que queres que se leia primeiro?

## ✏️ Exercício · As tuas fontes

1. Escolhe **1 fonte para títulos** e **1 fonte para texto** que combinem com as tuas 3 palavras (usa o Google Fonts).
2. Confirma que têm acentos portugueses.
3. Define a tua **escala de 5 tamanhos** (H1, H2, H3, texto, pequeno).
4. Escreve um anúncio curto do teu negócio usando a hierarquia: título, subtítulo, 1 linha de texto, contacto. Faz o teste do semicerrar.

```
Fonte de títulos: ____________  (porquê: ____________)
Fonte de texto:   ____________
Escala: H1 ___ · H2 ___ · H3 ___ · Texto ___ · Pequeno ___
```

## 📌 Resumo
- Cada família de letra tem personalidade: escolhe pelas tuas 3 palavras.
- Máximo 2 fontes: uma com carácter para títulos, uma legível para texto.
- Confirma os acentos portugueses.
- Hierarquia = tamanho, peso, cor, espaço e posição. Usa uma escala fixa.
